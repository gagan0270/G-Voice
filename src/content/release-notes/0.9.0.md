## transcribe.cpp

Local inference powered by transcribe.cpp and ggml.

transcribe.cpp enables new features in G-Voice, and accelerates
transcriptions for users. The most notable feature is
support for streaming models. You will be able to see
transcribed text as you are speaking with sub-150ms latency.

## Streaming Support

G-Voice supports native streaming models:

- Parakeet Unified for English Speakers
- Whisper Base Q8_0 for Multilingual & Kannada Speakers

A live streaming overlay lets you see what is being transcribed as you are speaking.

## New Model Support

Supported model families:
- Parakeet FastConformer-TDT
- Whisper (OpenAI / ggml)
- IBM Granite Family
- Mistral Voxtral Family
- Google MedASR
- Alibaba Qwen3 ASR
